HTML

Linguagem de marcação para estruturar páginas da web

Introdução

HTML (do inglês HyperText Markup Language, ou Linguagem de Marcação de Hipertexto) é a linguagem usada para descrever a estrutura e o significado do conteúdo de uma página da web. Ela não é uma linguagem de programação: não executa cálculos nem toma decisões, apenas indica ao navegador o que cada trecho representa, como um título, um parágrafo, uma imagem ou um link.

Na prática, o HTML trabalha ao lado de duas outras tecnologias. O CSS cuida da aparência e o JavaScript cuida do comportamento. Um bom documento HTML funciona mesmo sem as duas.

História

A linguagem foi criada pelo físico britânico Tim Berners-Lee, que trabalhava no CERN, na Suíça, para facilitar o compartilhamento de documentos entre pesquisadores. A primeira descrição pública do HTML circulou em 1991, junto com os primeiros navegadores e servidores da web.

A web deve ser um espaço aberto, onde qualquer pessoa possa publicar e acessar informação.

— Princípio que orienta a criação da web (paráfrase)

Com o crescimento da internet, a linguagem passou a ser padronizada por organizações como o W3C e, mais tarde, mantida em conjunto com o WHATWG.

Estrutura de um documento

Um documento HTML é formado por elementos. Cada elemento tem uma tag de abertura, um conteúdo e uma tag de fechamento, e pode receber atributos que complementam seu significado. O navegador transforma o documento em uma árvore de objetos chamada DOM.

O esqueleto mínimo de uma página é:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <title>Minha página</title>
  </head>
  <body>
    <h1>Olá, mundo</h1>
  </body>
</html>

Semântica

Semântica é o estudo do significado. Em HTML, escrever com semântica quer dizer escolher a tag que melhor descreve o conteúdo, e não a que apenas produz o visual desejado. Uma tag <div> não diz nada sobre o que carrega, enquanto <nav> deixa claro que ali está uma navegação.

Acessibilidade

Uma página acessível pode ser usada por todas as pessoas, incluindo quem navega apenas pelo teclado ou com leitor de tela. Boa parte disso vem de graça quando o HTML é semântico. Alguns cuidados básicos:

  • Descrever imagens com o atributo alt.
  • Associar cada campo de formulário a um <label>.
  • Usar os títulos h1 a h6 em ordem, sem pular níveis.
  • Garantir contraste suficiente entre texto e fundo.
  • Permitir navegar por tudo com Tab e ativar com Enter.
O que é ARIA?

ARIA é um conjunto de atributos, como aria-label e aria-current, que completam a semântica quando o HTML sozinho não é suficiente. A regra de ouro é usar primeiro a tag nativa correta e só então recorrer ao ARIA.

Versões

  1. 1995 – HTML 2.0, primeira especificação formal.
  2. 1997 – HTML 3.2, com tabelas e suporte a mais recursos visuais.
  3. 1999 – HTML 4.01, com ênfase na separação entre estrutura e estilo.
  4. 2014 – HTML5 se torna recomendação, trazendo video, audio, canvas e as tags semânticas.
